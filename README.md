# heart-failure-prediction-ml
A Python machine-learning project analysing clinical heart failure data using Logistic Regression, data cleaning, statistical analysis and visualisations to predict death events.
The dataset I have chosen for my report is "heart_failure_clinical_records.csv", It contains medical records of patients with heart failure. The goal is to predict whether the patient is Dead or Alive based on some of their medical conditions such as age, blood pressure, and serum creatinine levels etc.
